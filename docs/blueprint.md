# **App Name**: ClarityFlow

## Core Features:

- Text Input: Provides a user-friendly area for users to input text for analysis and humanization.
- AI Detection Analysis: Analyzes the input text to determine the likelihood of it being AI-generated and presents a confidence score to the user. Uses an LLM to determine how certain to be that the input text was generated by AI.
- Humanization Tool: Rewrites the AI-generated text with a more human-like tone and style, providing an improved version of the original content. The rewriting may involve using an LLM tool to check a given replacement word against its original use, so that the rewrite won't distort the meaning.
- Output Display: Presents both the AI analysis score and the humanized text in a clear and organized manner.

## Style Guidelines:

- Primary color: Tech-inspired blue (#4681C6) to evoke trust and modernity.
- Background color: Light, desaturated blue (#EBF4FA) to create a clean and professional interface.
- Accent color: A slightly brighter, more saturated blue (#5E81AC) is used for interactive elements and call to actions, creating an intuitive user experience.
- Font pairing: 'Space Grotesk' for headlines and short amounts of body text (sans-serif), 'Inter' for longer passages of body text (sans-serif).
- Simple, line-based icons to represent different functions and features.
- A clean and structured layout with clear visual hierarchy to guide users through the process.
- Subtle transitions and animations to enhance user engagement and provide feedback.
